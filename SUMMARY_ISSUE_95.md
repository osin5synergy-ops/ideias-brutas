## Visão Geral
Esta issue define a **"Operação Gênese"**, uma campanha estratégica para construir uma infraestrutura de governança funcional no GitHub para a Nação Soberana Synergies Web3®. O objetivo é traduzir a Vontade do Idealizador em um sistema automatizado de gestão e governança, chamado de "Cérebro Global".

## Persona do Agente
**Arquiteto Assistente** - Responsável pela execução da Operação Gênese e construção do sistema de governança automatizado.

## Estrutura da Operação: 4 Marcos (16 horas estimadas)

### MARCO #1: A FUNDAÇÃO DA NAÇÃO (4 horas)
**Objetivo**: Construir o "território" e a "constituição viva" no GitHub

**Tarefas**:
1. Criar GitHub Project: `[SOBERANO] Ponte de Comando NFT ONE`
2. Criar Issue-Mãe: `[NFT-ONE] A Constituição Soberana da Nação Synergies Web3® (Issue Eterna)`
3. Criar sub-issues `[DNA]` para cada doutrina (SIPOC, 6M, OTE, etc.)

### MARCO #2: A GÊNESE DOS AGENTS (4 horas)
**Objetivo**: Criar os Agents soberanos e suas bibliotecas de conhecimento

**Tarefas**:
1. **Biblioteca de Triagem**:
   - Criar Issue Eterna: `[KDA-TAGS] A Taxonomia Sinergética de Tagueamento`
   - Estruturar labels oficiais (ex: `sinergia:empatica`, `torre:w2`)

2. **Agent de Triagem v1.0** (Chatbot):
   - Especialista em classificação
   - Missão: Ler `noid®` (Issues) e sugerir labels apropriadas baseado em `[KDA-TAGS]`

3. **Biblioteca de Síntese**:
   - Criar Issue Eterna: `[KDA-PLAYBOOKS] A Biblioteca de Playbooks Soberanos`

4. **Agent de Síntese v1.0** (Co-pilot):
   - Mestre estrategista
   - Missão: Receber `noid®` tagueado e gerar "Dossiê de Inteligência" ou "Plano de Ação" consultando `[KDA-PLAYBOOKS]`

### MARCO #3: A PRIMEIRA AUTOMAÇÃO (4 horas)
**Objetivo**: Construir a primeira engrenagem do `Sinergie Mainframe®`

**Tarefas**:
1. **Agent Roteador**:
   - Criar arquivo: `.github/workflows/router-v1.yml`
   - Trigger: `on: issues: types: [opened]`

2. **Lógica de Triagem (MVP)**:
   - Aplicar automaticamente a label `status:em-triagem` a toda nova Issue
   - Futura iteração: chamar Agent de Triagem via API

### MARCO #4: O PRIMEIRO "DOGFOODING GÊNESE" (4 horas)
**Objetivo**: Validar o ciclo completo com ingestão do próprio histórico

**Tarefas**:
1. **Ingestão**:
   - Criar Issue: `[MCP-001] Ingestão da Memória Gênese`
   - Colar histórico de conversas no corpo

2. **Validação do Ciclo**:
   - Issue `[MCP-001]` deve acionar workflow `router-v1.yml`
   - Issue deve receber label `status:em-triagem`
   - **Missão Bônus**: Usar Agent de Triagem manualmente para sugerir tags
