## 🏛️ O Oráculo do GitHub

Bem-vindo ao repositório governado pelo **Oráculo do GitHub** - nossa fonte única da verdade sobre como o "Aparelho de Estado" funciona.

### O que é o Oráculo?

O Oráculo é um agente inteligente que:
- 🔍 **Monitora** novos noids® (issues) e responde proativamente
- ⚖️ **Governa** Playbooks (PRs) segundo a doutrina SI-p-POO-OC-ote®
- 🧠 **Aprende** e propõe melhorias à própria base de conhecimento

### Arquitetura do Sistema

```
┌─────────────────────────────────────────────┐
│        [KDA-DOC] Issue Eterna               │

    └─> Agent Cronos (registra NF-Atos®)
```

## 🚀 Como Começar

### 1. Entenda o Vocabulário

| GitHub | Sinergético | Significado |

### 3. Convoque o Oráculo

Em qualquer issue ou PR:

```

```

O Oráculo responderá com referências à documentação e sugestões de próximos passos.

## 📋 Criar um noid® (Issue)

Use os templates disponíveis:

1. **[KDA-DOC]** - Para documentação soberana
2. **[DOC]** - Para cromossomos específicos
3. **[PROPOSTA]** - Para sugerir melhorias à doutrina
4. **Bug Report** - Para relatar não-conformidades
5. **Feature Request** - Para propor novas funcionalidades

## 🔧 Criar um Playbook (PR)

1. Crie um branch a partir de `main`
2. Faça suas mudanças
3. Abra um PR referenciando o noid® relacionado
4. O **Agent de Conformidade** verificará automaticamente
5. Aguarde review da comunidade
6. Após merge, o **Agent Cronos** registrará um NF-Ato®

## 🤖 Agents Ativos

### Agent de Conformidade
Verifica se PRs seguem a doutrina SI-p-POO-OC-ote®:
- ✅ Descrição presente
- ✅ Referência a noid®
- ✅ Tamanho adequado
- ✅ Documentação atualizada

### Agent Cronos
Registra mudanças automaticamente:
- 📝 Monitora arquivos `.md` e `.yml`
- 🕐 Adiciona NF-Atos® ao Log Soberano
- 🔗 Cria histórico auditável
