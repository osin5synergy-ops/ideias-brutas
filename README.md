## Calculator: A + B + C

Simple calculator implementation that adds three numbers together.

### Usage

#### As a Python function:
```python
from calculator import add_three_numbers

result = add_three_numbers(1, 2, 3)
print(result)  # Output: 6
```

#### As a command-line tool:
```bash
python3 calculator.py
```

This will prompt you to enter three numbers and display their sum.
